# Publikacja polityki przez GitHub Pages

Zalecany adres:

`https://toooldtocode.github.io/LibertyKeyboard/privacy-policy.html`

## Włączenie strony

1. Wypchnij katalog `docs/` do publicznego repozytorium
   `TooOldToCode/LibertyKeyboard`.
2. Na GitHubie otwórz `Settings` → `Pages`.
3. W sekcji `Build and deployment` wybierz `Deploy from a branch`.
4. Wybierz gałąź `main`, katalog `/docs` i zapisz.
5. Poczekaj na publikację i otwórz powyższy URL w oknie prywatnym przeglądarki.
6. Sprawdź, czy strona działa bez logowania i bez ograniczenia geograficznego.
7. Ten sam URL wpisz w Play Console i pozostaw w aplikacji.

## GitHub czy GitHub Pages?

Bezpośredni link do pliku w repozytorium bywa czytelny, ale GitHub Pages jest
bezpieczniejszym wyborem dla Google Play: daje zwykłą publiczną stronę HTML bez
interfejsu edycji repozytorium. Wymóg „non-editable” oznacza, że odwiedzający nie
może edytować treści polityki jak formularza lub współdzielonego dokumentu.
Deweloper oczywiście może publikować kolejne wersje polityki.

Przed wysłaniem aplikacji nie używaj URL, dopóki nie odpowiada kodem HTTP 200.
